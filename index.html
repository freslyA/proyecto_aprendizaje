VALOR PRESENTE

Definición

Es un método de la matemática financiera que permite determinar el valor actual de una cantidad de dinero que se recibirá o pagará en el futuro, considerando factores como la inflación, tasa de interés y las oportunidades de inversión. Su objetivo es determinar el equivalente actual de un valor futuro, tomando en cuenta que el dinero tiene diferente valor según el momento en que se utilice.

Su fórmula es: VP = VF / (1 + i)^n

Ejemplo

Una empresa recibirá $15,000 dentro de 3 años por una inversión realizada. Si la tasa de interés anual es del 8%, se desea conocer cuál es el valor presente de ese dinero.

Datos:

  • Valor futuro (VF) = $15,000
  • Tasa de interés (i) = 8% o 0.08
  • Tiempo (n) = 3 años

Aplicando la fórmula:

  • VP = $15,000 / (1 + 0.08)^3
  • Resultado: VP = $11,907.49

Esto significa que recibir $15,000 dentro de 3 años equivale aproximadamente a tener $11,907.49 en la actualidad, considerando una tasa de interés anual del 8%.

Código Base

let valorFuturo = 15000;
let tasaInteres = 0.08;
let tiempo = 3;

let valorPresente = valorFuturo / Math.pow((1 + tasaInteres), tiempo);
console.log("Valor Presente: $" + valorPresente.toFixed(2));

VALOR FUTURO

Definición

Es un concepto de la matemática financiera que permite calcular cuánto valdrá una cantidad de dinero en el futuro después de haber generado intereses durante un determinado período de tiempo. Este cálculo es utilizado para analizar inversiones, ahorros y capitales que aumentan su valor con el paso del tiempo.

Su fórmula es: VF = C * (1 + i)^n

Ejemplo

Una persona deposita $8,000 en una cuenta bancaria que ofrece una tasa de interés anual del 6% durante 4 años. Se desea conocer cuánto dinero tendrá al finalizar ese tiempo.

Datos:

  • Capital (C) = $8,000
  • Tasa de interés (i) = 6% o 0.06
  • Tiempo (n) = 4 años

Aplicando la fórmula:

  • VF = $8,000 * (1 + 0.06)^4
  • Resultado: VF = $10,099.82

Esto significa que tener $8,000 en la actualidad equivale aproximadamente a tener $10,099.82 dentro de 4 años, considerando una tasa de interés anual del 6%.

Código Base

let capitalInicial = 8000;
let tasaInteres = 0.06;
let tiempo = 4;

let valorFuturo = capitalInicial * Math.pow((1 + tasaInteres), tiempo);
console.log("Valor Futuro: $" + valorFuturo.toFixed(2));

INTERÉS SIMPLE

Definición

Es un método de cálculo financiero en el cual los intereses se generan únicamente sobre el capital inicial durante un período determinado. A diferencia del interés compuesto, los intereses no se acumulan al capital, por lo que el monto ganado o pagado se mantiene constante en cada período. Este tipo de interés es utilizado comúnmente en préstamos a corto plazo, inversiones básicas y operaciones financieras simples.

Su fórmula es: IS = C * i * t

Ejemplo

Una persona solicita un préstamo de $12,000 con una tasa de interés simple anual del 9% durante 3 años. Se desea calcular cuánto interés deberá pagar al finalizar el período.

Datos:

  • Capital (C) = $12,000
  • Tasa de interés (i) = 9% o 0.09
  • Tiempo (t) = 3 años

Aplicando la fórmula:

  • IS = $12,000 * 0.09 * 3
  • Resultado: IS = $3,240

Esto significa que la persona deberá pagar $3,240 de interés al finalizar los 3 años, además del capital inicial prestado.

Código Base

let capitalInicial = 12000;
let tasaInteres = 0.09;
let tiempo = 3;

let interesSimple = capitalInicial * tasaInteres * tiempo;
console.log("Interés Simple: $" + interesSimple.toFixed(2));

INTERÉS COMPUESTO

Definición

El interés compuesto es un método de cálculo financiero en el cual los intereses generados se suman al capital inicial, permitiendo que en cada período se generen nuevos intereses sobre el monto acumulado. Este proceso provoca un crecimiento progresivo del dinero con el paso del tiempo. El interés compuesto es ampliamente utilizado en inversiones, cuentas de ahorro, créditos bancarios y financiamiento empresarial.

Su fórmula es: MA = C * (1 + i)^n

Ejemplo

Una persona invierte $10,000 en una entidad financiera que ofrece una tasa de interés compuesto anual del 12% durante 4 años. Se desea calcular el monto acumulado al finalizar el período.

Datos:

  • Capital (C) = $10,000
  • Tasa de interés (i) = 12% o 0.12
  • Tiempo (t) = 4 años

Aplicando la fórmula:

  • MA = $10,000 * (1 + 0.12)^4
  • Resultado: MA = $15,735.19

Esto significa que la persona obtendrá un monto acumulado de $15,735.19 al finalizar los 4 años.

Código Base

let capitalInicial = 10000;
let tasaInteres = 0.12;
let tiempo = 4;

let monto = capitalInicial * Math.pow(1 + tasaInteres, tiempo);
console.log("Monto: $" + monto.toFixed(2));

CUOTAS Y PAGOS PERIÓDICOS

Definición

Las cuotas y pagos periódicos son cantidades de dinero que se pagan en tiempos establecidos, por ejemplo cada mes o cada semana. Se usan para dividir una deuda grande en partes más manejables, facilitando el pago a lo largo del tiempo.

Su fórmula es: C = P * [i*(1+i)^n] / [(1+i)^n - 1]

Ejemplo

Si una persona compra una computadora en $1,200 y decide pagarla en 12 cuotas mensuales con un interés del 1% mensual, se puede calcular la cuota fija.

Datos:

  • Préstamo (P) = $1,200
  • Tasa de interés mensual (i) = 1% o 0.01
  • Número de cuotas (n) = 12

Resultado: Cuota mensual ≈ $106.62

Código Base

let prestamo = 1200;
let interes = 0.01;
let cuotas = 12;

let cuotaMensual = prestamo * (interes * Math.pow(1 + interes, cuotas))
                 / (Math.pow(1 + interes, cuotas) - 1);
console.log("Cuota mensual: $" + cuotaMensual.toFixed(2));

TABLA DE AMORTIZACIÓN FRANCESA

Definición

La tabla de amortización francesa es un sistema de pago donde las cuotas son iguales durante todo el préstamo. En cada cuota, la parte de interés va disminuyendo y la parte de capital amortizado va aumentando, pero el total a pagar siempre es el mismo.

Ejemplo

Si una persona solicita un préstamo de $5,000 a 10 meses con un interés mensual del 2%, pagará la misma cuota cada mes hasta cancelar la deuda.

Datos:

  • Monto (P) = $5,000
  • Tasa mensual (i) = 2% o 0.02
  • Número de cuotas (n) = 10

Resultado: Cuota fija ≈ $553.74 por mes.

Código Base

let monto = 5000;
let interes = 0.02;
let cuotas = 10;

let cuotaFija = monto * (interes * Math.pow(1 + interes, cuotas))
              / (Math.pow(1 + interes, cuotas) - 1);
console.log("Cuota fija: $" + cuotaFija.toFixed(2));

TABLA DE AMORTIZACIÓN ALEMANA

Definición

La tabla de amortización alemana es un sistema donde el capital se paga en partes iguales y las cuotas van disminuyendo con el tiempo. Esto ocurre porque los intereses se calculan sobre el saldo restante, que baja cada período al amortizar siempre el mismo capital.

Ejemplo

Si una persona pide un préstamo de $4,000 a 4 meses con un interés mensual del 3%, cada mes pagará la misma cantidad de capital ($1,000), pero los intereses irán bajando.

Datos:

  • Monto (P) = $4,000
  • Tasa mensual (i) = 3% o 0.03
  • Número de cuotas (n) = 4
  • Capital por cuota = $4,000 / 4 = $1,000

Las cuotas serán: $1,120 → $1,090 → $1,060 → $1,030 (van disminuyendo).

Código Base

let capital = 4000;
let interes = 0.03;
let cuotas = 4;
let capitalFijo = capital / cuotas;

for(let i = 1; i <= cuotas; i++){
    let interesDelPeriodo = capital * interes;
    let totalCuota = capitalFijo + interesDelPeriodo;
    capital -= capitalFijo;
    console.log("Cuota " + i + ": $" + totalCuota.toFixed(2));
}
