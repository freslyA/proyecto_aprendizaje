VALOR PRESENTE

Definición

Es un método de la mátematica financiera que permite determinar el valor actual de una cantidad de dinero que se recibirá o pagará en el futuro, considerando factores con la inflación, tase de interés y las opiortunidades de inversión. su objetivo es determinar el equivalente actual de un valor futuro, tomando en cuenta el dinero que tiene diferente valor segun el momento en que se utilice.

Su formula es: VP = VF / (1 + i)^n

Una empresa recibira $15000 dentro de 3 años por una inverion realizada. si la tasa de interez anual es del 8%, se desea conocer cual es el valor presente de ese dinero.

Datos:

  • Valor futuro (VF) = $15000
  • Tasa de interés (i) = 8% o 0.08
  • Tiempo (n) = 3 años

    • Aplicando la formula:

  • VP = $15000 / (1 + 0.08)^3
  • Resultado: VP = $11938.25

    • Esto significa que recibir $15,000 dentro de 3 años equivale aproximadamente a tener $11 ,907.49 en la actualidad, considerando una tasa de interés anual del 8%. 

    let valor Futuro = 15000;
let tasaInteres = 0.08;
let tiempo = 3;

            
    
let valorPresente = valorFuturo / Math.pow(1 + tasaInteres, tiempo);
console.log("Valor Presente: $" + valorPresente.toFixed(2));

    Cuotas y Pagos Periódicos

    Definición

    Las cuotas y pagos periódicos son cantidades de dinero que se pagan en tiempos establecidos, por ejemplo cada mes o cada semana.

    Explicación

    Ejemplo: Si una persona compra una computadora en $1200 y decide pagarla en 12 meses, deberá pagar una cuota mensual de $100.

    Código Base

    
let cuotaMensual = 100;
let meses = 12;

let totalPagar = cuotaMensual * meses;

console.log("Total a pagar: $" + totalPagar);

    Tabla de Amortización Francesa

    Definición

    La tabla de amortización francesa es un sistema de pago donde las cuotas son iguales durante todo el préstamo.

    Explicación

    Ejemplo: Si una persona solicita un préstamo de $5000 a 10 meses, pagará la misma cuota cada mes hasta terminar de cancelar la deuda.

    Código Base

    
let cuota = 250;

if(cuota > 0){
    console.log("La cuota mensual es: $" + cuota);
}

    Tabla de Amortización Alemana

    Definición

    La tabla de amortización alemana es un sistema donde el capital se paga en partes iguales y las cuotas van disminuyendo con el tiempo.

    Explicación

    Ejemplo: Si una persona pide un préstamo de $4000 a 4 meses, cada mes pagará la misma cantidad de capital, pero los intereses serán menores, por eso las cuotas bajan poco a poco.

    Código Base

    
let capital = 4000;
let meses = 4;

for(let i = 1; i <= meses; i++){
    console.log("Pago del mes " + i);
}

    Test

    1. El valor presente representa el dinero actual de una cantidad futura.

    2. El valor futuro calcula cuánto dinero habrá en el futuro.

    3. En el interés simple, los intereses se calculan solo sobre el capital inicial.

    4. En el interés compuesto, los intereses generan nuevos intereses.

    5. En la amortización alemana las cuotas aumentan cada mes.
